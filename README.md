# Exasite — Центр допомоги

Статичний сайт центру допомоги платформи Exasite (UA / EN): інструкції, швидкий старт, демонстрації, глосарій, словник іконок, пошук.
Збирати нічого не потрібно — це звичайні HTML, CSS, JS і зображення.

## Запуск локально

```bash
cd site
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Структура

| Шлях | Що це |
|---|---|
| `site/index.html` | Сторінка, порядок підключення скриптів |
| `site/app.js` | Логіка: маршрути (`#slug`), пошук, глосарій, прогрес, демонстрації |
| `site/styles.css` | Стилі (світла й темна теми) |
| `site/i18n.js` | Тексти інтерфейсу UA / EN |
| `site/data/meta.js` | Розділи, джерела, швидкий старт, контакт підтримки |
| `site/data/content-exa01…04.js` | Статті UA (EXA-01…EXA-04) |
| `site/data/content-en.js`, `content-en-exa04.js` | Статті EN |
| `site/data/content-exa05-11.js` | Розділи EXA-05, 08–11 (чернетки) |
| `site/data/demos.js` | Інтерактивні демонстрації |
| `site/data/glossary.js`, `icons.js`, `map.js` | Глосарій, словник іконок, карта відповідності |
| `site/img/` | Скриншоти у WebP (`*_EN` — англійський інтерфейс), `crops/` — фрагменти для словника іконок |

## Що не зберігається в репозиторії

Текстові інструкції (документи EXA-01…EXA-11 UA/EN, PDF) і оригінальні скриншоти PNG лежать окремо, у Dropbox проєкту.
Тут лише те, що безпосередньо використовує центр допомоги.

## Як вносити зміни

- Текст статті — у відповідному `site/data/content-*.js` (блоки `p`, `steps`, `table`, `callout` тощо; посилання між статтями — `[[slug|текст]]`).
- Новий скриншот — у `site/img/` у WebP, назва `EXA-NN_SNN.webp` (EN: `…_EN.webp`).
- Кожна зміна — окремий коміт з описом, що й чому змінено.

## Тестові дані

Контакт підтримки в `site/data/meta.js` (`HC.support`) — тестовий, замінити перед показом клієнтам.
